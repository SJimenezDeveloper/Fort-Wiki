## 📱 ¿Qué es Fort-Wiki?

**Fort-Wiki** es una app Android para consultar y buscar información sobre cosméticos y novedades del universo Fortnite, creada como proyecto de aprendizaje y desarrollo avanzado en Kotlin.

## 🚀 Funcionalidades principales

- 🔎 **Búsqueda de cosméticos:** Filtra skins y objetos por nombre, tipo y otros parámetros.
- 📰 **Noticias al instante:** Consulta las últimas novedades oficiales de Fortnite.
- 🖼️ **Galería de imágenes:** Visualiza detalles y variantes de cada cosmético.
- 📋 **Detalles completos:** Info ampliada, descripción y rareza.
- 🛠️ **MVVM y buenas prácticas:** Código limpio y escalable, ViewModels y Repositorios.
- 🔐 **Integración API segura:** Consulta la [Fortnite API](https://fortnite-api.com/) de forma eficiente.

## ⚙️ Instalación y ejecución

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/tuusuario/FortUJI.git
   cd FortUJI
2. **Abre el proyecto en Android Studio (“Open an existing project” y selecciona la carpeta del proyecto).**

3. **(Opcional) Configura tu clave API si es necesaria en local.properties o donde la hayas definido.**

4. **Ejecuta en un emulador o dispositivo Android.**
